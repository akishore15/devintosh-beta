# devintosh
Devintosh is a place to deploy private environments to code. If you want me to add a feature, then post it in the "Issues" section. Let's get started!
## OS
The operating system you can use will be Ubuntu by default.
## Environments
### Which platform is my Devintosh located on?
It is a Docker container.
#### How do I login?
The program should return the IP address of the container. Then, you can SSH into the container via using:
```bash
ssh root@1.2.3.4```
Where 1.2.3.4 is where the IP address should be replaced.
##### But what about the password?
The password, you can set it up while the program will still be running.
